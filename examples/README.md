# Example Programs

This folder contains sample programs for the compiler.

## Folders
- inputs/: source programs written in the current language subset
- outputs/: expected output or generated assembly ideas

## Included examples
1. arithmetic.c
2. conditional_if.c
3. loop_and_function.c
4. nested_conditions.c
5. mixed_loop_logic.c
6. harder_compute_chain.c

These examples cover arithmetic, branching, nested conditionals, loops, and function-based computation.
